SOLUSINDO ASET ASISTEN WHATSAPP

Hubungkan WhatsApp Anda.

Pasangkan nomor bisnis sebagai perangkat tertaut. Percakapan baru akan diteruskan ke konsultan AI Anda.

Akses pengaturan

Buka halaman ini dengan npm run connect dari folder backend/whatsapp, atau gunakan token admin lokal.

Memeriksa koneksi…

Menunggu koneksi WhatsApp.

  1. Buka WhatsApp pada ponsel dengan nomor bisnis Anda.
  2. Pilih Setelan → Perangkat tertaut → Tautkan perangkat.
  3. Scan QR ini. Status di halaman akan berubah menjadi Tersambung.

Kode pemasangan:

Pada ponsel, pilih Perangkat tertaut → Tautkan perangkat → Tautkan dengan nomor telepon, lalu masukkan kode di atas.

WhatsApp siap menerima pesan.

Kirim pesan dari nomor lain, misalnya “Halo, saya mencari rumah untuk investasi”. Balasan chatbot akan muncul di WhatsApp pengirim.
